# Photos

VB6 Photos viewer (`Photos.exe`) that starts with a splash form and uses MSCOMCTL plus the Shell Image Viewer (`shimgvw.dll`) on the main form for browsing packaged images. Open `Photos.vbp` in the VB6 IDE.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `Photos` (`Photos.vbp`) | VB6 | WinForms exe | Photos |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `Photos.vbp`

## Requirements

- Visual Basic 6.0 IDE
- Registered OCX/DLL dependencies referenced by the `.vbp` (may need to be installed separately):
  - `MSCOMCTL.OCX`
  - `shimgvw.dll`
